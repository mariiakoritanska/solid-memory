# Valentine Flask 💘

Милий веб-сайт на Flask, створений для того, щоб зізнатися в коханні.

## 🧠 Що це?

Це веб-сторінка, яка задає запитання:
**"Чи готовий ти терпіти мої істерики вічно?"**

- Якщо натиснути **"Так!"** — з'явиться величезний котик і зізнання у коханні.
- Якщо натиснути **"Ні"** — кнопка зменшується і просить натиснути "Так".

## 🚀 Як розгорнути через Render

1. Створи репозиторій на GitHub і додай туди всі файли (`app.py`, `templates/`, `requirements.txt`, `README.md`)
2. Перейди на [Render](https://render.com) і створи новий **Web Service**
3. Обери цей репозиторій
4. Налаштування:
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python app.py`
   - **Runtime**: Python

Render автоматично надасть тобі посилання типу:  
👉 `https://valentine-flask.onrender.com`
